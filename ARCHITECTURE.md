# Архитектура 0.5.3

Host ComfyUI содержит native BaseModel/ModelPatcher API и proxy без diffusion weights. Отдельный subprocess на каждый выбранный CUDA UUID владеет FSDP Shard(0); meta init и checkpoint row slices предотвращают полную H3-копию на каждом rank. Session сериализует requests в safetensors/JSON, проверяет cancellation и завершение workers; готовый conditioning хранится в run-stage и очищается на end_run.

FSDP groups оборачивают block и вспомогательные projections. GPU placement сохраняет shards в VRAM, CPUOffloadPolicy — в RAM, ATS — в scoped cuMemAllocManaged pool с CPU preference. All-gather/activations используют ordinary CUDA pool. FSDP reshard_after_forward=True и явный boundary reshard не оставляют полные группы между requests. Prefetch управляется agreed memory estimate.

Между runs ResidentBackend сохраняет GPU/ATS локальные DTensor shards и buffers в CPU-only LocalShardState, вместе с scalar Safe GEMM/QK metadata. FSDP graph удаляется, hook cycles собираются GC на границе фаз; ATS MemPool не удерживается worker/factory closure. Следующий вызов реконструирует тот же graph/policy и загружает local cache без safe_open для weights, norm vectors или нового bounds collective. Header/quant metadata читается для архитектуры/identity. CPUOffloadPolicy не нуждается в этой копии. Active GPU/CPU/ATS placement никогда не подменяется другой policy.

FP32 sequence wire — default baseline path; normalized FP16 wire opt-in добавляет global V MAX на каждый H3 attention block. MLP off/manual использует boundary budget только для bounded preparation, без per-block allocator samples. Progress writes throttled (first MLP/status/error forced). Wall timers отделяют plan, compute enqueue, final wait, finite check, result serialization и host deserialization. Эти wall times не являются exclusive CUDA kernel times; actual overlap требует optional profiler.

H3 sequence режет token rows до первого DiT block. Token path собирает full KV; Ulysses выполняет QKV head all-to-all и inverse output exchange с padding heads. После последнего block собирается FP32 residual для native final layer. Малые empty-shard sequences явно используют replicated compute. Numerical safety и MLP chunk policy независимы. Qwen использует собственный token/GQA contract и replicated native vision.

Поддержка Comfy проверяется по capabilities/signatures. Custom CUDA providers проходят isolated numeric probes на каждом device, включая local padded heads для Ulysses. Политика общая для ranks; kernel/OOM exceptions завершают session. UI JSON мигрируется до десериализации positional widgets.

Memory budgets учитывают driver free и reusable allocator cache; pending-stream active blocks не засчитываются. Только Auto MLP читает occupancy после реального conditioning expansion. Safe FP16 Linear bounds собираются из CPU row shards одним MAX при первоначальной загрузке; постоянного full FP32 weight cache нет. Safe sequence использует FP32 wire по умолчанию. В opt-in FP16 wire QKV масштабируются до exchange, MAX V scale общий для ranks, FP32 restoration делается после обратного обмена. Финальный residual не сужается. Первый MLP progress сохраняется до chunk loop; последующие updates throttled и входят в aborted RPC report. Optional profiler различает selected policy, реальные provider calls, SDPA operator, prefetch helper ranges и CUDA kernel names.

Weight owner reuse отделён от prompt/run state: неизменные checkpoint/config/patch/role_options переиспользуют Session. CPU deactivation/phase release сохраняет pinned shards, clears stage/cache; смена владельца той же роли закрывает старую модель. Qwen clones и MLP variants всегда инициализируют native patcher lifecycle поля. Cancelled retained RPC хранит входные/stage файлы и частично собранные rank replies до завершения фонового drain, затем end_run/idle. Error paths не переиспользуют damaged workers.
